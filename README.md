🌐 Interfaces Web

Repositório destinado aos projetos, atividades e exercícios desenvolvidos na disciplina de Interfaces Web.

📚 Sobre a disciplina

A disciplina de Interfaces Web aborda conceitos e práticas relacionados ao desenvolvimento de interfaces para aplicações web, explorando desde a estruturação de páginas até a criação de layouts responsivos, acessíveis e visualmente agradáveis.

🛠️ Tecnologias utilizadas

Durante a disciplina, serão utilizadas tecnologias como:

HTML5
CSS3
JavaScript
Git e GitHub
Visual Studio Code

🎯 Objetivos
Aprender os fundamentos do desenvolvimento web;
Criar interfaces modernas e responsivas;
Praticar HTML, CSS e JavaScript;
Desenvolver projetos utilizando boas práticas;
Aprender a utilizar Git e GitHub para versionamento;
Melhorar a experiência e a usabilidade das interfaces.
